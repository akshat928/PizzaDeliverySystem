# Pizza Delivery System

This repository contains the frontend web interface for a pizza delivery system. The project focuses on a clean, responsive layout designed to display menu items, handle search queries, and encourage users to download mobile applications. 

## Key Features

* **Responsive Layout:** Designed to scale naturally across various screen sizes, from mobile phones to desktop monitors.
* **App Store Integration:** Sections dedicated to linking users to mobile versions of the application on iOS and Android.
* **Component-Based Styling:** A styled navigation system, hero section, and structured grid configurations for content.

---

## Project Structure

The project uses a flat directory structure for easy navigation and development.

* **index.html** - Contains the semantic structure and main content markup of the webpage.
* **style.css** - Handles the visual styling, positioning rules, and layout responsiveness.
* **README.md** - General documentation and setup instructions for the codebase.

### Visual Assets
* **logo.jpg** - Main branding image for the platform header.
* **search.png** - Core asset for the interactive search bar feature.
* **app_store.png & google_play_store.png** - Official store badges for mobile downloads.
* **bgi1.jpg, bgi4.jpg, bgi5.jpg** - Background imagery used across the homepage sections.

---

## Technologies Used

* **HTML5** (50.9%) - Provides the semantic structural foundation.
* **CSS3** (49.1%) - Manages custom styling, grid alignments, and responsive behaviors.
